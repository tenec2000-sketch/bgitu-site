# Сайт БГИТУ — учебный макет

Публичная часть сайта Брянского государственного инженерно-технологического университета: 41 страница по аудиту `bgitu_redesign_audit.md` из чата «Сайт Бгиту». Личный кабинет делается отдельно — здесь только страница входа `lk.html`.

> Макет сайта, не официальный сайт вуза. Факты взяты с bgitu.ru (ноябрь 2026); блоки с пометкой «демо-данные макета» заполнены условными данными.

## Как запустить

- **Windows:** двойной клик по `Запустить сайт.bat` — откроется браузер с сайтом.
- **macOS / Linux:** двойной клик по `start.command` (или `./start.command` в терминале).
- **Вручную:** в папке сайта выполнить `python -m http.server 8792` и открыть http://127.0.0.1:8792/

Нужен Python 3 (или Node.js). Сайт открывается и двойным кликом по `index.html`, но тогда не работают установка «как приложение» и офлайн-кэш.

## Что внутри

| Раздел | Страницы |
|---|---|
| Университет | `index`, `university`, `institutes`, страницы институтов `inst-*`, `college`, `campus`, `garden`, `sveden`, `docs`, `press`, `staff` |
| Поступающим | `admission`, `programs` (каталог + калькулятор ЕГЭ), `program` (карточка направления), `target`, `school`, `transfer`, `paid`, `international` |
| Студенту | `student`, `schedule` (звонки, неделя, выгрузка в календарь), `eos`, `scholarships`, `library`, `life`, `career`, `dpo`, `help` (FAQ, титульный лист по ГОСТ, помощник), `lk` |
| Наука и прочее | `science`, `aspirantura`, `news`, `article`, `contacts` (телефонный справочник), `sitemap`, `privacy`, `404` |

На всех страницах: три темы (кнопка «Тема»: Бумага, Сурик, Латунь), версия для слабовидящих («Доступность»), поиск по сайту `Ctrl + K`, номер учебной недели, установка на телефон как приложение (PWA).

## Как править

Страницы **собираются** скриптом — правьте исходники в `src/`, а не готовые `.html`:

```
python src/build_site.py src/bgitu-landing.html src/trail.js .
```

- `src/bgitu-landing.html`, `src/bgitu-landing-STYLE.md` — исходный макет команды и описание стиля;
- `src/site_engine.py` — шапка, темы, общие стили и компоненты;
- `src/site_extra.py` — меню, доступность, PWA, неделя, cookies;
- `src/build_site.py` — главная, университет, институты, поступление, кампус, новости, контакты и все данные (направления, кафедры, новости);
- `src/pages_extra.py` — остальные страницы по аудиту;
- `src/trail.js` — фон «Тушь ×3» (линии, пыль).

Заметность линий фона — переменная `--trail-op` в `src/site_engine.py` (1 — максимум, сейчас 0.5).

`mockups/` — снимки страниц в трёх темах (`mockups/index.html` — галерея).
